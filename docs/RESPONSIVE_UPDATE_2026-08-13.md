# Responsive UI Update

- Global visible scrollbars removed while scrolling remains functional.
- Admin and Vendor sidebars become off-canvas below 1150 CSS px.
- This intentionally activates around 175% browser zoom on typical desktop monitors.
- Admin/Vendor hamburger controls stay available below 1150 px.
- Vendor hamburger event wiring was fixed.
- Customer/Public navigation becomes an off-canvas drawer below 1150 px.
- Drawer closes with close button, overlay click, Escape, or selecting a link.
- Main-content sidebar offsets are removed in compact mode.
- Page-level horizontal overflow is suppressed.
- Tables retain internal scrolling on smaller screens, but no scrollbar chrome is shown.
